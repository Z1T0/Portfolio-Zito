Cores

Neutros frios e um azul

A base é neutra: branco, cinzas azulados e quase preto. O azul #3458FF é a única cor de marca e serve para destaque, link, foco e botão de destaque. O verde aparece só como status. Clique numa cor para copiar o hex; RGB, HSL e contraste são calculados na hora.

Paleta

Valores do tema claro. Os do escuro estão na seção seguinte.

Variações de opacidade

Use opacidade para sobreposições e vidro. Para texto, prefira as cores sólidas.

Gradientes

O azul só entra em gradiente quando há algo para destacar.

Tema escuro

O mesmo sistema, no escuro

O tema segue o do sistema operacional e pode ser trocado no botão da lua, no topo. A escolha fica salva no navegador e vale para a home também. No escuro os neutros invertem: --white vira a superfície escura e --ink vira o texto claro, então quase nenhum componente precisa de regra própria. O azul continua como preenchimento com texto branco, e o texto de destaque (--accent) clareia para #8EA2FF, porque #3458FF como texto no escuro dá só 3,73:1.

Os mesmos componentes com os tokens de cada tema. Não muda com o botão do topo.
